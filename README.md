# Prism Atoll

Bilingual marketing and support site for the Apple Vision Pro game. Published from `main` on GitHub Pages.

- English landing page, support and privacy at the site root.
- French equivalents under `fr/`.
- Playable browser demo under `preview/` with mouse, touch and keyboard controls.
- Localized screenshots in `assets/en/` and `assets/fr/`.

For a local preview, run `python3 -m http.server 8080` from this directory.
